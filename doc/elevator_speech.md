# Histour

## 한 줄 정의
> 외국인 관광객을 위해, ChatGPT 기반 실시간 챗봇과 AI 영상 콘텐츠를 활용하여, 한국 역사 관광지를 선택지형 스토리 게임처럼 경험하게 하고 관광지 방문을 유도하는 서비스

---

## 문제
- 대상: 서울을 방문한 외국인 관광객  
- 문제: 한국 역사와 인물에 대한 이해 부족으로 관광지가 단순한 “장소”로 소비됨  
- 한계: 기존 관광 정보는 설명 위주라 흥미와 몰입도가 낮음  
- 기회: 스토리와 상호작용 요소를 결합하면 관광지에 대한 관심을 높일 수 있음  

---

## 해결 아이디어
- 핵심 아이디어:  
  관광지를 배경으로 역사 인물과 대화하는 **선택지형 스토리 게임** 제공

- 사용자 흐름:  
  1) 관광지 선택  
  → 2) 관련 인물 등장  
  → 3) 선택지 기반 대화 진행  
  → 4) 챗봇 반응 생성  
  → 5) 결말 분기 (좋음 / 나쁨)  
  → 6) AI 영상 연결  

---

## 기술 / 구현

### 시스템 구성

| 영역 | 구성 | 사용 기술 |
|------|------|-----------|
| Frontend | 사용자 UI, 선택지 인터랙션 | Next.js, React, TypeScript, Tailwind CSS |
| Backend | API, 상태 관리 | FastAPI 또는 Node.js |
| AI (대화) | 역사 인물 챗봇 | ChatGPT API |
| AI (번역) | 다국어 처리 | ChatGPT API / 번역 API |
| 콘텐츠 | 결말 영상 | Sora 기반 생성 영상 + YouTube / AWS S3 |
| 데이터 | 관광지/인물/선택지 | JSON 또는 DB |
| 배포 | 웹 서비스 | Vercel |

---

### 동작 흐름

| 단계 | 설명 |
|------|------|
| 1 | 사용자가 관광지 선택 |
| 2 | 해당 관광지와 연결된 역사 인물 로드 |
| 3 | 3~4개의 선택지 제공 |
| 4 | 선택값을 백엔드로 전달 |
| 5 | ChatGPT API가 맥락 기반 응답 생성 |
| 6 | 대화 반복 진행 |
| 7 | 마지막 선택에서 결말 분기 |
| 8 | 결말에 따라 영상 제공 |

---

## MVP / 배포
- MVP 기능:
  - 관광지 선택 UI
  - 선택지 기반 대화 시스템
  - ChatGPT API 연동 챗봇
  - 결말 분기 + 영상 연결
  - 다국어 지원

- 배포 방식:
  - Vercel을 통한 프론트엔드 배포  
  - 영상은 YouTube 또는 AWS S3 활용  

---

## 차별점
- 정보 제공이 아니라 **게임형 경험 기반 관광 유도**
- 선택지 + AI 챗봇 결합 구조로 몰입감 강화
- 결말 영상으로 사용자 선택의 결과를 시각적으로 제공
- 외국인을 위한 실시간 번역 기반 접근성 확보
