# Histour

## 한 줄 정의
> 외국인 관광객을 위해 ChatGPT 기반 실시간 챗봇과 AI 영상 콘텐츠를 활용하여 한국 역사 관광지를 선택지형 스토리 게임처럼 경험하게 하고 관광지 방문을 유도하는 서비스

---

## 문제
- 고객:
  - 한국 여행을 고려 중이거나, 한국 문화 콘텐츠에 관심 있는 외국인 사용자  

- Pain Point:
  - 한국 역사와 관광지에 대한 정보가 낯설고 어렵게 느껴져 관심을 갖기 어려움  
  - 기존 관광 정보는 설명 중심이라 흥미를 유발하지 못하고 방문으로 이어지기 어려움  

- Vitamin:
  - 스토리 기반의 체험형 콘텐츠를 통해 흥미를 먼저 유도하면 관광지 방문 의향을 높일 수 있음  

---

## 해결 아이디어
- 핵심 아이디어:  
  관광지를 배경으로 역사 인물과 대화하는 **선택지형 스토리 게임** 제공

- 사용자 흐름:  
  → 1) 관광지 선택 → 역사 인물 등장  
  → 2) 3~4개의 선택지로 대화 진행 (챗봇 반응)  
  → 3) 선택에 따라 스토리 진행  
  → 4) 마지막 선택에서 결말 분기  
  → 5) 결과에 따라 영상 제공 → 방문 흥미 유도

---

## 기술 / 구현

| 영역 | 구성 | 사용 기술 |
|------|------|-----------|
| Frontend | 사용자 UI, 선택지 인터랙션 | Next.js, TypeScript, Tailwind CSS |
| Backend | API, 상태 관리 | FastAPI |
| AI (대화) | 선택지 기반 역사 인물 챗봇 | ChatGPT API |
| AI (번역) | 다국어 처리 | ChatGPT Translation API  |
| 콘텐츠 | 결말 영상 | Sora 기반 생성 영상 + YouTube / AWS S3 |
| 데이터 | 관광지/인물/선택지 | PostgreSQL |
| 배포 | 웹 서비스 | Vercel |

---

## MVP / 배포
- MVP 기능:
  - 관광지 선택 UI
  - 선택지 기반 대화 시스템
  - ChatGPT API 연동 챗봇
  - 결말 분기 + 영상 연결
  - 다국어 지원

- 배포 방식:
  - Vercel을 통한 배포  
  - 영상은 YouTube 또는 AWS S3 활용  

---

## 차별점
- 정보 제공 및 선택형 게임 경험 기반 관광 유도
- 선택지 + AI 챗봇 결합 구조로 몰입감 강화
- 결말 영상으로 사용자 선택의 결과를 시각적으로 제공
- 외국인을 위한 실시간 번역 기반 접근성 확보

## (산학트랙) 검증

| 항목 | 내용 |
|------|------|
| 인터뷰 대상 | 한국 역사 관광에 관심이 있는 외국인 |
| 핵심 결과 | - 정보 탐색은 주로 인터넷 검색 기반<br>- 단순 연도 및 사실만 나열되면 흥미를 갖기 힘듦 <br>- 이야기 없이 정보만 제공되면 겉핥기식 경험이라고 인식 <br>- 관광지 선택 시 서사가 가장 중요한 요소  |
| 인사이트 | - 사용자에게 필요한 것은 단순 정보가 아닌 이야기 중심의 맥락 <br>- 특정 인물의 행동의 이유, 역사적 배경 등 서사 기반 컨텐츠가 차별화 포인트 |

---

## 결론
- 왜 필요한가:
  - 기존 역사 관광 정보는 단순 사실 전달에 그쳐 사용자에게 깊은 흥미와 이해를 제공하지 못함
  - 특히 외국인에게는 한국 역사를 이해하는 데 큰 도움이 되지 못함
  - 역사적 맥락와 인물의 서사를 기반으로 한 몰입형 경험 제공이 필요하며, 이를 통해 사용자가 실제로 관광지를 방문하도록 유도할 수 있음
- 기대 효과:
  - 스토리 기반 체험을 통한 관광지에 대한 흥미 및 이해도 향상
  - 단순 정보 소비를 넘어선 능동적인 참여 경험 제공
  - 콘텐츠 몰입을 통한 관광지 방문 의향 증가 및 행동 유도
  - 외국인 접근성 개선 및 글로벌 사용자 확장 가능
