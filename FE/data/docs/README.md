# FE Data Guide

## Folder Structure

- `raw/`
  - 원본 CSV를 그대로 보관하는 폴더
- `docs/`
  - 어떤 데이터를 어디에 쓰는지 정리하는 문서

## What Each Dataset Does

- `AREA_PRSN_2021.csv`
  - 관광지와 관련 인물을 연결하는 메인 데이터
  - 장소 설명, 관련 인물, 장면 제목, 키워드에 사용

- `AREA_CLTUR_2023.csv`
  - 장소 설명을 더 보강하는 서브 데이터
  - 특히 조선 말기와 근대 전환기 설명 보강에 사용

- `OLD_ROAD_2023.csv`
  - 옛길, 유배길, 이동 경로 같은 흐름형 서사에 사용
  - 수원화성, 추사 유배길 같은 장소의 현장 포인트 보강

- `CLTUR_FSTVL_2023.csv`
  - 지금도 즐길 수 있는 행사나 장면 연결에 사용
  - 수원화성문화제 같은 현재형 체험 소개에 반영

- `RECOMEND_SIGHTS_2023.csv`
  - 추천 관광지와 행사용 장소 보강
  - 제주목관아 야간개장, 금정산성축제처럼 실제 방문 포인트 연결

- `KMOVIE_DATA_2026.csv`
  - SNS/콘텐츠 반응 참고 데이터
  - 외국인에게 익숙하거나 반응이 좋은 장소를 보여주는 보조 지표로 사용

- `FOREIGNER_UTILIZATION_202208.csv`
  - 구 단위 외국인 방문/소비 데이터
  - 홈과 상세에서 "외국인 반응" 요약 문구 생성에 사용

- `CLTUR_VR_2023.csv`
  - 아직 화면에는 반영하지 않았음
  - 추후 "미리 둘러보기"나 VR 링크 영역에 붙일 후보

## Screen Mapping

- 홈 카드
  - 장소명, 대표 이미지, 조선 시대 맥락, 외국인 반응, 관련 인물 수

- 관광지 상세
  - 대표 장면, 현장 포인트, 외국인 반응, 활용 데이터, 관련 인물

- 인물 선택 / 대화
  - 장소와 연결된 대표 장면을 기준으로 인물 소개와 대화 톤 구성

## Current Curation Rule

- 조선 시대와 연결감이 분명한 장소만 우선 선별
- 공항 필터와 연결이 쉬운 서울/수원/부산/제주 장소 중심
- 외국인에게 설명하기 쉬운 서사가 있는 장소 우선
